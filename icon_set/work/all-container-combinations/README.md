# Defined container pair gallery

Only the 2,709 container pairs in combination_data.json are composed, using the resolved main/sub mapping in the generated catalog. Multiple mapped source variants produce 2,724 previews. Every drawing is displayed on a 64 × 64 canvas; wide text retains its native profile width and remains flagged for layout review.

Source validation failures and unsupported measurements are visible but are not approved fits. The previous unrestricted gallery URL now serves this same corrected paired gallery. Rebuild with python3 -m icon_set.scripts.build_paired_container_combinations.
