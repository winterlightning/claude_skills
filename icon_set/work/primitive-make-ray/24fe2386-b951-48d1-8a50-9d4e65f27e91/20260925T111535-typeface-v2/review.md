# AD with typeface v2

Uses the exact native v2 A and D, translated only. Neither letter has been redrawn, scaled, nor snapped to the SOLO48 grid. Header dashes are omitted as before.

The browser has been enlarged to centerline bounds (4,4)-(44,44) so the native letters have room. The preview is still 48×48 with 4-unit strokes.

Visually reviewed in light and dark at 48px and 384px: the rounded A and native D read clearly and retain open counters.

This is a review candidate, not a strict SOLO48 pass. The expanded frame misses the SQUARE envelope by 2 units on each side. Native glyph coordinates also trigger integer-grid and spacing findings, including D bowl/stem internal clearance. The full unmodified findings are in validation.txt and checks.json. No profile constants or validation exceptions were changed.
