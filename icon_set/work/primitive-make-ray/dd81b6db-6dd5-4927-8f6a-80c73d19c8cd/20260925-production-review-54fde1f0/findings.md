# Question Mark Message Bubble

Rounded bubble, diagonal tail, clear question hook and detached dot. Taller envelope gives the mark more space.

Keyshape: VRECT_L. Tall frame or upright figure uses the 32-by-40 centerline envelope.

Omissions: None.

Construction references: message-square

Strict QA: review.

- mic [bubble]: bubble and question are 8 apart on centerlines nearest (24, 4)<->(24, 12); SOLO48 requires at least 8 (ink clearance 4) unless the contact is declared with a scoped `connect` relationship
