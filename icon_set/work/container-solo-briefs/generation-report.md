## Construction and references

New drawings use source-specific reductions and native integer coordinates. Original supplied sources were rendered; useful Lucide original and atomic-debug references were inspected for silhouette, coherent paths and shared nodes. Human reference full_body_ref.png and user.svg guided people. Diagonal direction and poses are intentional. Major reductions include three grapes, simplified airplane strokes, fewer steam/fingerprint turns, and reduced facial/factory details. Existing drawings were reused only after source comparison and current validation.

New stick figures have radius-5 heads with 8-unit centerline / 4-unit ink neck clearance and an upper torso tangent aligned to the head. New bust constructions use touching head/body ink. Untouched existing solo geometry keeps its established construction.
