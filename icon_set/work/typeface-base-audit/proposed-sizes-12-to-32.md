# Proposed typeface sizes: heights 12–32

Proposal only. No glyph geometry or catalog sizes were changed.

Use the current 24-unit visible-height base. For each requested integer height H, proposed visible width = floor(base_width × H / 24 + 0.5). Dimensions include the stroke; round half upward. Scale the complete visible envelope, including its stroke, then fit the horizontal envelope to this integer width. Keep curve control points smooth rather than rounding every point.

This proposes bounding dimensions. The current build only implements the 24-unit base; these other sizes still need size-specific geometry/export support and visual checks.

Regular glyphs have proportional stroke H / 6 (2 at height 12; 4 at height 24; 5.333 at height 32). Period, hyphen, and underscore use a base stroke of 24 and therefore stroke H. This retains the current all-glyphs-height-24 treatment; they are substantially larger than punctuation in ordinary text.

Suggested common heights: 12, 16, 20, 24, 28, 32. All integer heights between them are included below.

## Complete proposal

Every table cell is width × height.
