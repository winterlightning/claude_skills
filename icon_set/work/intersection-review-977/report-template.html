Method and scope

The fixed cohort is stored with the report generator. The original graph cleanup function is instrumented only to expose rejected candidates; its acceptance guards are unchanged. Shared or anchored endpoints and lines carrying junctions are protected. Cubics are supported; the additional arc-aware pass samples arcs at ≤0.08-unit nominal spacing and rounds samples to 9 decimals. The original model API omits arcs as cutting boundaries.

Each candidate preview applies proposed line endpoint changes to a temporary model, checks full model validation and unchanged centerline bounds, then restores the model. A manual preview may fail ink or model guards and is not an approved change. This scan does not detect every short branch, curved hook, duplicate path or semantic problem.
