## Tasks and description

This project's task list is `TASKS.md` at the repo root and its
description is `DESCRIPTION.md`, both synced with the TodoPusher
app. To add work for the agent, add a `- [ ]` line to `TASKS.md`; to
describe the project, edit `DESCRIPTION.md`. The exact format
and rules for both are in `TASK_INSTRUCTIONS.md`; read it before editing either file.
